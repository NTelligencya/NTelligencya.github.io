Type the Indigenous NT keyboard, right here

This page is a stand-alone practice keyboard for the Indigenous NT Integrated Keyboard, the free Keyman layout published by SIL Global for the eleven official languages of the Northwest Territories. Unlike the scripts in a typical operating-system keyboard gallery, this layout is not built into Windows or macOS, so there is nothing to switch on in your settings. Everything below runs in this page: hold the Alt key on Windows (or the right Option key on a Mac) while you type, and this page reproduces the same characters the real keyboard would produce.

Nothing here needs installing, which matters on school Chromebooks and locked-down devices where students cannot add a system keyboard themselves.

Type here, now

Do thisClick the practice box further down, then hold Alt (Windows) or Option (Mac) and press a letter. Add Shift as well for the capital or second version.

Why it worksThis page listens to the physical key you press, the same way the real keyboard driver does, so the drill is a faithful rehearsal even without installing anything.

Install it for real

For everyday typingGet the free Keyman app, then add the Indigenous NT keyboard, from keyman.com/keyboards/indigenous_nt (medium confidence on current install steps; the vendor page is the source of truth).

Where it runsWindows, macOS, iOS, Android, and a web/bookmarklet version, so the same layout follows a student between a school desktop and a phone.

About this keyboard

CoversEleven official NWT languages on one integrated layout, so there is no switching between separate keyboards.

ConventionDiacritics are typed after the vowel or consonant they belong to (the Vowel First Dene convention), matching the printed layout card.

Publisher & licenceSIL Global, via the open-source Keyman project (MIT licence, medium confidence; see sources).

This page was built by reverse-engineering the keyboard's own published source file, not by re-typing the printed diagram, so the character set below should match the real keyboard exactly. If you spot a mismatch against a keyboard your students already have installed, it is worth checking against the source linked at the bottom of this page before using this in class.
