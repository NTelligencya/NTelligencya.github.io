Learn by turning the dials yourself.

Reading about a mechanism is one thing; watching it run is another. These interactive tools let you practise a skill or see a system work, one step at a time. Each runs entirely in your browser; nothing is installed, nothing is uploaded, and every tool works offline once the page has loaded.

Built for classrooms, workshops and self-paced learners across the Northern Territory. New tools are added as they are ready.
