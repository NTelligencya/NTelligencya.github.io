Available ✓ current
Available Shown automatically when you're active on a device. You can also choose it yourself, but only if nothing more accurate is already in play, for example you can't manually set Available while your calendar shows you're in a meeting.
Busy
Busy You're online but focused. Notifications still show as normal; colleagues just see that you're occupied. Teams also sets this automatically while you're in a call, in a meeting, or presenting.
Do not disturb
Do not disturb The only status that changes what reaches you. Banner notifications are switched off and incoming calls go straight to voicemail. Chat messages still arrive, you just aren't interrupted by them. Anyone on your priority access list can still call you and will still show as normal.
Be right back
Be right back A manual-only status. It never gets set automatically; you choose it yourself for a short break, so colleagues know you'll be back shortly rather than genuinely away.
Appear away
Appear away Set automatically if you've been inactive on your computer for a few minutes, if your computer locks, or if the Teams mobile app has been sitting in the background for a while. You can also choose it manually if you want to look away without going fully offline.
Appear offline
Appear offline Hides your presence from colleagues completely; they'll see you as offline even though you're still using Teams normally in the background. It's also the only status that stays in place indefinitely once you set it manually, rather than expiring after a day or a week.
↺ Reset status
Reset status Clears anything you've set manually and hands presence back to Teams, which then calculates it automatically again from your activity, calls, and calendar.
⏱ Duration, set how long a status lasts
Duration You can choose how long a manually set status should last. If you don't set a duration yourself, Busy and Do not disturb default to one day, most other statuses default to seven days, and Appear offline stays until you change it.

Source: Microsoft Learn, "User presence in Teams," last updated 16 July 2026.
